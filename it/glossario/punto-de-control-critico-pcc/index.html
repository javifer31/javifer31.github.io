Punto di Controllo Critico (PCC)

Cos'è un Punto di Controllo Critico (PCC)?

Un Punto di Controllo Critico (PCC) è la fase di un processo alimentare in cui si applica un controllo essenziale per prevenire, eliminare o ridurre a un livello accettabile un pericolo per la sicurezza dell'alimento. È un concetto centrale del sistema HACCP.

Ogni PCC richiede limiti critici definiti, sorveglianza continua, azioni correttive e registrazioni documentate.
