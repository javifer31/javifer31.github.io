What this folder does that the server one does not

What sets this folder apart from the server one is not where the file sits: it is that the folder knows what should be inside it and in what state.

Required-document lists: you define per folder which documents it must hold, and the module warns when a list is short. The incomplete folder is spotted before the audit, not during it.

Expiry date and calendar: each document carries its own, and the module comes with month, week, day and agenda views, by expiry date or by modification date. A hundred due dates stop being a hundred dates in a spreadsheet.

Approved or pending: both states are visible in the list, and one filter gathers everything awaiting review into a single view. An unapproved document is not mistaken for a current one.

What SharePoint or Drive do not cover

A cloud folder stores the files and keeps their change history, and it does that well. The problem is not where the file sits: a loose file knows nothing about itself.

It does not know which documents should be in its folder, so it cannot say one is missing.

It has no expiry date: the certificate lapses and the file sits there, exactly the same.

It does not tell an approved document from one awaiting approval, which is half of an audit.

It does not sit next to the record that applies the procedure, nor next to the incident that breaches it.

And it is not opened from the shop floor with the same login used to fill in a shift check.

Frequently asked questions

How is it different from SharePoint or Drive?

A shared folder stores files and keeps their change history, and it does that well. What it does not do is know which documents should be in that folder, warn you that a certificate is expiring, tell an approved document from one awaiting approval, or sit next to the record that applies the procedure. That is what Solved's document manager adds.

Does it control versions?

Yes. Every document shows its version number, so whoever opens it knows which one they are looking at and there are never two copies going round with nobody sure which rules.

How are expiry dates controlled?

Every document has a review date and an expiry date. The module comes with a calendar view — month, week, day and agenda — that can be sorted by expiry or by modification date, plus a list of everything awaiting review. Tracking due dates stops being a sheet with a hundred dates on it.

What are required-document lists?

They are the list of documents a folder must hold. They are defined per folder and the module itself warns when a list is short, so the incomplete folder is spotted before the audit rather than during it.

Is it a separate module?

Documents is a module of the system, with its own menu entry, and it is switched on like the rest. Supplier approval, on the other hand, is not a separate module: it is this same document manager applied to the supplier, alongside their goods-in incidents.

Do we have to reorganise all the documents to start?

No. The tree of folders and subfolders is built however suits you, so you can reproduce the one you already use and upload what is current. What changes is not the organisation: it is that each document now has a date, a status and an owner.
